CFG → DCG: el cambio concreto

CFG — terminales dentro de la gramática
gramatica = {
    'S':   [['NP', 'VP']],
    'NP':  [['Det', 'N'], ['N']],
    'VP':  [['V', 'NP'], ['V']],
    'Det': [['la'], ['el'], ['un']],
    'N':   [['estudiante'], ['libro'], ['cafe']],
    'V':   [['lee'], ['veo']]
}

En DCG las reglas estructurales no cambian. Lo que cambia es que las palabras salen al léxico y llevan sus rasgos:
DCG — reglas igual, pero las palabras tienen memoria
gramatica = {
    'S':  [['NP', 'VP']],
    'NP': [['Det', 'N'], ['N']],
    'VP': [['V', 'NP'], ['V']],
}

lexico = {
    'la':         {'cat': 'det', 'gen': 'fem',  'num': 'sing'},
    'el':         {'cat': 'det', 'gen': 'masc', 'num': 'sing'},
    'estudiante': {'cat': 'n',   'gen': 'fem',  'num': 'sing'},
    'libro':      {'cat': 'n',   'gen': 'masc', 'num': 'sing'},
    'lee':        {'cat': 'v',   'num': 'sing', 'accion': 'leer'},
    'veo':        {'cat': 'v',   'num': 'sing', 'accion': 'ver'}
}

# "la estudiante lee" → válida.
# "la libro veo" → falla por orden y rasgos.
